📖 Installatie-handleiding (klik om uit te klappen)
1. Supabase (gratis database)
→ Ga naar supabase.com, maak een gratis project aan.
→ Kopieer uit Settings → API: de Project URL en anon key.

2. SQL-script uitvoeren in Supabase
→ Ga naar SQL Editor en voer dit script uit: 3. API-Football (optioneel, voor automatische uitslagen)
→ Ga naar RapidAPI API-Football
→ Maak gratis account aan → klik "Subscribe" op de Basic (gratis) tier
→ Kopieer je X-RapidAPI-Key en plak die hierboven.

4. GitHub Pages (gratis hosting)
→ Sla deze pagina op als index.html
→ Maak een GitHub repository aan en upload het bestand
→ Ga naar Settings → Pages en zet de bron op "main branch"
→ Je site is live op gebruikersnaam.github.io/reponaam

🤖 Automatische uitslagen via GitHub Actions

Voeg dit bestand toe als .github/workflows/uitslagen.yml in je GitHub repository. Het script haalt elke avond om 23:00 automatisch de uitslagen op.

Voeg deze Secrets toe in GitHub (Settings → Secrets → Actions):

  • SUPABASE_URL — je Supabase project URL
  • SUPABASE_KEY — je Supabase service_role key
  • APIFOOTBALL_KEY — je RapidAPI key
